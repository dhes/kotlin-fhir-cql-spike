WHO's immunization test cases, run in this browser

WHO's SMART Guidelines immunizations guide (0.2.0) comes with test cases: a patient, a date and a PlanDefinition, and what applying it should give. This page runs every one of them here, in this browser tab, with no server. For each case, ohs-foundation/kotlin-fhir-workflow applies the PlanDefinition to the patient ($apply), and cqframework's CQL evaluator evaluates the CQL it calls over ohs-foundation/kotlin-fhir resources, all compiled from Kotlin to WebAssembly.

A case passes when the CarePlan contains the number of resources WHO's test expects and, where the test gives one, the same guidance text.

A prototype, not a WHO or Open Health Stack release. Source: dhes/kotlin-fhir-cql-spike.
